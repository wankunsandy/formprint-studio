Otomatisasi Dokumen Ujian

FormPrint Studio

Ubah Google Form menjadi naskah soal siap cetak (DOCX & PDF) lengkap dengan gambar dan tabel kisi.

Pastikan pengaturan formulir tidak dibatasi login akun tertentu (bisa dibuka secara publik).

Mengekstrak soal, mengunduh gambar, & menyusun dokumen cetak...

Lihat Panduan Kode Tag Template Word (Jinja2)

Gunakan tag berikut di dalam dokumen Microsoft Word (.docx) Anda:

{{ judul_form }}
{{ deskripsi_form }}

{% for bagian in daftar_bagian %}
{{ bagian.nama_bagian }}
{{ bagian.petunjuk }}

{% for item in bagian.soal %}
{{ item.no_global }}. {{ item.pertanyaan }}
{% if item.ada_gambar %}{{ item.gambar }}{% endif %}

{% if item.tipe == 'pilihan_ganda' %}
   {% for opt in item.opsi %}({{ opt.huruf }}) {{ opt.teks }} {% if opt.ada_gambar %}{{ opt.gambar }}{% endif %}   {% endfor %}
{% elif item.tipe == 'pg_kompleks' %}
   {% for opt in item.opsi %}[  ] {{ opt.huruf }}. {{ opt.teks }}
   {% endfor %}
{% elif item.tipe == 'benar_salah' %}
   [Buat Tabel 3 Kolom: {%tr for b in item.baris %}{{ b.sub_no }}. {{ b.teks }} | [  ] | [  ]{%tr endfor %}]
{% elif item.tipe == 'kisi_pilihan_ganda' %}
   [Buat Tabel Matriks: {%tr for b in item.baris %}{{ b.no_angka }}. {{ b.teks }} | ( ) | ( ) | ( ) | ( ){%tr endfor %}]
{% elif item.tipe == 'menjodohkan' %}
   [Buat Tabel 2 Kolom: Kolom Kiri loop item.kiri, Kolom Kanan loop item.kanan]
{% else %}
   Jawab: ........................................................................
{% endif %}
{% endfor %}
{% endfor %}
